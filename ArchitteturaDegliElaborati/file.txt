vim <nome_file.vhdl>
- crea un file VHDL

all'interno del file VHDL:
- :i per modificare
- Esc -> :wq per salvare e uscire

dopo essere usciti:
- ghdl -a <nome_file.vhdl> -> controlla se ci sono errori

Prendere / Creare testbench
- compilare se manca qualcosa
- uscire e fare ghdl -a <nome_file_testbench.vhdl> -> per controllare se ci sono errori 

Fare ghdl -e <nome_file_testbench> per creare l'eseguibile

./<nome_file_testbench> --wave=wave.ghw per eseguire l'eseguibile

gtkwave wave.ghw -> con il file creato andiamo a simulare
